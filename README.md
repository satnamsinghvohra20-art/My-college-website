## 🚀 Quick Start & Development

### 1. Run Locally with Node.js
```bash
# Start local live server
npm run dev

# Or using standard python server
python -m http.server 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Generate Academic Presentation & PDF Report
```bash
# Install python requirements
pip install -r scripts/requirements.txt

# Generate 15-Slide Presentation (.pptx)
npm run generate:ppt

# Generate 13-Page University Project Report (.pdf)
npm run generate:pdf

# Or generate both at once:
npm run generate:all
```

### 3. Run with Docker
```bash
docker-compose up -d --build
```
Access at [http://localhost:8080](http://localhost:8080).

## 🌟 Key Highlights & Engineering Features

1. **Student & Faculty ERP (`portal.html`)**:
   - Circular SVG Live Attendance Gauge (86.4% Good Standing vs 75% Mumbai University Ordinance 0.119 threshold).
   - 3D Flip Digital Student Smart ID Card with barcode scanner.
   - Printable Examination Hall Ticket with seat number and exam center verification.
   - Central Railway Student Concession & Bonafide Certificate Generator.
   - **Dynamic QR Attendance Projector HUD**: 10-second rotating cryptographic tokens eliminating proxy check-ins.

2. **Data Science & AI Predictive Hub (`analytics.html`)**:
   - Client-side Machine Learning models running in-browser:
     - **Logistic Sigmoid Defaulter Classifier** (Real-time debarment risk probability).
     - **Ordinary Least Squares (OLS) SGPA Forecaster** with multi-parameter correlation.
     - **K-Means Academic Clustering Engine** classifying cohorts into Remedial, Balanced, and Honors.
   - Interactive live parameter sensitivity sliders and CSV export capabilities.

3. **Autonomous Voice AI Assistant (*ChandiBot*)**:
   - Integrated across all pages with Web Speech API for voice recognition (`🎤`) and speech synthesis (`🔊`).
   - Handles admissions criteria, syllabus lookups, fee calculations, and campus directions.

4. **NEP 2020 Compliance Engine**:
   - Interactive CBCS Major/Minor credit calculator with Academic Bank of Credits (ABC) validation.
   - Autonomous Bloom's Taxonomy Question Paper Balancer.
